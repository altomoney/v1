# DUSD USM tests

[DUSDUsm](../../contracts/usm/DUSDUsm.sol) and [DUSDAdvancedPermissionsUsm](../../contracts/usm/DUSDAdvancedPermissionsUsm.sol) derive from Aave's GHO code. Because these contracts are fork adaptations, separate Branching Tree Technique (BTT) specifications (`.tree` files) and BTT test suites are intentionally not being added for them. Existing conventional tests in this folder remain maintained.

This BTT exemption applies only to `DUSDUsm` and `DUSDAdvancedPermissionsUsm`.
