# AltoVault tests

[AltoVault](../../../contracts/lending/vault/AltoVault.sol) is adapted from Morpho's MetaMorpho V1.1. Because it is a fork, separate Branching Tree Technique (BTT) specifications (`.tree` files) and BTT test suites are intentionally not being added for this contract. Existing conventional tests in this folder remain maintained.

This BTT exemption applies only to `AltoVault`.
